## 고친 내용

1. 로그인 안내 줄의 괘선을 없앴다. 글자와 버튼만 남고, 테두리는 버튼 하나뿐이다.
2. 목록 위아래 괘선을 없애고 글과 글 사이(`li + li`)에만 괘선을 둔다. 관련 뉴스처럼 목록 첫 글은 위 여백 없이 시작한다.
3. "이전 글 더 보기"를 글자 버튼(`nx-link-button`)으로 바꾸고 왼쪽에 붙였다.
4. 답글의 세로선을 없애고 20px 들여쓰기로만 묶는다. 답글 입력칸의 테두리 하나만 남는다.
5. `html[data-nx] .nx-talk-input:focus-visible { outline: none; }`으로 핑크 링을 막았다. 초점은 입력칸 테두리 색으로만 보인다.
6. 두 버튼을 기본 `nx-btn`(44px)으로 바꿨다.
7. 누른 좋아요는 잉크색과 함께 굵기 600으로 보인다. `aria-pressed`는 그대로다.
8. 제목 줄 아래 간격을 관련 뉴스와 같은 24px로 맞추고, 로그인 안내 줄은 좁으면 버튼이 아랫줄로 내려가게 했다.
9. 빈 상태 문구를 로그인 여부로 나눴다. 로그인 전에는 "아직 글이 없어요."만 보인다.

## 다시 점검

- 구획 안 테두리를 다시 뽑았다. 로그인 전: "로그인하기" 버튼 하나. 로그인 후: 글쓰기 칸과 "글 올리기" 버튼, 글이 둘 이상이면 글 사이 괘선. 겹치는 선은 없다.
- 구획 안 버튼 높이는 모두 44px.
- 휴대폰 폭 375px: 가로 넘침 0px. 마지막 글 아래가 하단 주문 버튼·탭바에 가리지 않는다(마지막 줄 514px, 고정 바 684px부터).
- 라이트 테마에서 글쓰기 칸, 글, 답글 모두 보인다.
- 눌러 보기: "로그인하기" → 로그인 창이 열리고 Esc로 닫힘. 로그인 전 "좋아요" → 로그인 창이 열림. 글쓰기 칸 클릭 → 테두리만 밝아짐.
- 확인하지 못한 것: 실제 로그인한 상태의 글 올리기·좋아요·지우기·답글은 로그인이 필요해 화면에서 눌러 보지 못했다. 서버 쪽 쓰기·봇 차단·일주일 정리는 백엔드 테스트와 로컬 DB로 따로 확인했다.
- 개발 서버 콘솔에는 `ws://localhost:8082/ws/stream` 연결 실패만 남는다. 백엔드를 8082로 띄워 생긴 로컬 실행 문제이고 토론 구획과는 관계없다.
