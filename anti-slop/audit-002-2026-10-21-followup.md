### 1. 종목 이름 넘침 (R-03)
- 이름 `Txt`에 `flexShrink: 1`, 이름 칸에 `minWidth: 0`을 줘서 긴 이름이 말줄임(…)으로 끝나고 추이선·가격과 겹치지 않습니다.
- 화면 폭과 글자 크기 배율로 이름에 남는 폭을 계산하고, 96pt보다 좁으면 추이선과 범례 문장을 빼서 이름에 자리를 줍니다. 계산 결과 360pt 화면(글자 1.0배)에서는 추이선이 빠지고, 375pt 이상에서는 남습니다. 글자 크기를 키우면 더 넓은 화면에서도 빠집니다.
- 위치: `mobile/src/screens/HomeScreen.js` (`TRAIL_WIDTH`, `MIN_NAME_WIDTH`, `showTrail`).

### 2. 상태 표시줄 겹침 (R-03)
- 위쪽 안전 영역 높이만큼 바탕색 막을 스크롤 영역 위에 고정해서, 스크롤한 카드가 시계·배터리 밑으로 비치지 않습니다. 막은 터치를 막지 않습니다(`pointerEvents="none"`).
- 위치: `HomeScreen.js` `styles.statusCover`.

### 3. 웹 배포 전 로그인 버튼 (R-26)
- 로그인 상태를 세 가지로 나눴습니다. 웹이 아직 알려 주지 않으면 '모름', 알려 줬다면 '로그인'이나 '로그아웃'입니다.
- **모름**(지금 배포된 웹): "내 자산과 손익은 내 계좌 탭에서 볼 수 있어요" 카드가 뜨고, 누르면 내 계좌 탭이 열립니다. 로그인한 사용자에게 로그인을 권하지 않습니다.
- **로그아웃**: 로그인 안내 카드를 보여 줍니다. 버튼은 `/login` 대신 `/mypage`를 엽니다. 웹은 로그인하지 않은 사용자가 `/mypage`에 들어오면 로그인 창을 띄우고(`src/App.tsx` `PRIVATE_ROUTES`), 로그인한 사용자에게는 내 계좌를 보여 주므로, 어느 쪽이든 홈으로 튕기지 않습니다.
- 토큰이 만료돼 401이 오면 로그아웃으로 바꾸지 않고, 웹에 새 토큰만 요청합니다.
- 위치: `mobile/App.js` (`auth`, `LOGIN_PATH`, `expireToken`), `HomeScreen.js` 자산 카드 분기.

### 4. 첫 로딩 중 이동 무시 (R-26)
- WebView가 로딩 중일 때 들어온 이동 요청을 `pendingPath`에 보관했다가, 로딩이 끝나면(`onLoadEnd`) 보냅니다. 페이지를 새로 불러올 때(`onLoadStart`)는 다시 '준비 안 됨'으로 돌려서, 로그인 후 페이지를 다시 불러오는 동안의 이동도 잃지 않습니다.
- 위치: `mobile/src/WebPane.js`.

### 5. 계좌·시세 오류 표시 (R-27)
- `usePortfolio`가 상태(`idle`, `loading`, `ready`, `error`)와 `reload`를 돌려줍니다.
- 로그인했는데 계좌가 아직 없으면 "내 계좌를 불러오는 중이에요", 실패하면 "내 계좌를 불러오지 못했어요 / 화면을 아래로 당기면 다시 불러와요"를 보여 줍니다. 이미 받은 계좌가 있는데 갱신이 실패하면, 자산 카드 아래에 "계좌를 새로 받지 못해 마지막으로 받은 값이에요"를 덧붙입니다.
- 시세가 화면에 있는데 갱신이 실패하면 "새 시세를 받지 못해 마지막으로 받은 값을 보여 주고 있어요. 아래로 당겨 다시 불러오세요." 알림이 뜹니다. 다음 요청이 성공하면 사라집니다.
- 당겨서 새로고침은 시세와 계좌를 함께 다시 읽습니다.
- 위치: `mobile/src/market.js` `usePortfolio`, `HomeScreen.js`.
