### 1. 비로그인 계좌 화면 (R-27, R-26)
- **감사 정정:** 화면을 열면 로그인 창은 뜹니다. 감사 때 `<dialog>`만 찾아서 `div[role=dialog]` 창을 놓쳤습니다. 실제 문제는 로그인 창을 닫으면 "로그인 상태를 확인하고 있어요."만 남고 다시 열 방법이 없는 것이었습니다(운영 사이트에서 재현).
- 이제 확인 중일 때만 그 문구를 보여 줍니다. 확인이 끝났는데 로그인하지 않았으면 "로그인이 필요한 화면이에요"와 함께 [로그인하기], [시장 둘러보기] 두 버튼을 보여 줍니다.
- 함께 발견한 문제: 로그인 뒤 돌아갈 주소 목록에 `/loan`이 빠져 있어, 대출 화면에서 로그인하면 홈으로 갔습니다. 목록에 추가했습니다(`src/lib/auth.ts`).
- 확인: `/loan` 진입 → 로그인 창 열림 → 닫기 → 안내와 두 버튼 표시 → [로그인하기] → 창이 다시 열림 → Escape로 닫힘.
- 위치: `src/App.tsx`, `src/styles/next-pages.css`(`.nx-gate`).

### 2. 칭호 글자색 (R-25, R-34)
- 색표 33개는 그대로 두고, 화면에서는 `--title-ink` 변수로만 넘깁니다. 다크에서는 흰색 55%, 라이트에서는 잉크(#1b1726) 15%를 섞습니다. 색상 계열은 유지됩니다.
- 계산값: 다크에서 패널·돋움·핑크 바탕 모두 최저 5.23:1("흑우"는 1.01 → 회색으로 읽힘), 라이트에서 흰 바탕·돋움·핑크 바탕 모두 최저 5.34:1.
- 적용 위치: 랭킹 닉네임 위 칭호, 칭호 화면 카드와 이름표(`titleInkStyle`, `.has-title-ink`).
- 색이 33가지라는 문제(#11)는 승인 범위 밖이라 그대로입니다.

### 3. 뉴스 띠 상승률 (R-25)
- 공통 등락색 규칙이 더 구체적이라 뉴스 띠 전용 색을 덮고 있었습니다. 뉴스 띠 규칙의 선택자를 더 구체적으로 바꿨습니다.
- 밝은 뉴스 면의 상승색은 #e0263c(4.06:1, 미달)에서 #c01f34(5.26:1)로 바꿨습니다. 하락 #2f5fe0은 4.78:1 그대로입니다.
- 위치: `src/styles/next.css` 뉴스 띠 부분.

### 4. 핑크·적색 면 위 흰 글자 (R-25)
- 새 토큰을 추가했습니다: `--up-fill` #e0263c, `--down-fill` #2f5fe0(다크), 라이트에서는 기존 `--up`/`--down`. 매수·매도 버튼, 주문표 탭, 주문 제출 버튼, "○○ 거래하기" 버튼이 이 면을 씁니다. 흰 글자 대비는 4.65:1 / 5.48:1입니다.
- 핑크 면 위 글자는 흰색 대신 무대색 #12101c(6.19:1)로 바꿨습니다: 차트 현재가 꼬리표, 뉴스 태그, 랭킹의 "나" 표시, 완료한 미션 번호.
- `DESIGN.md`의 `button-buy`, `button-sell`, `news-tag`, `news-up`과 색 설명을 같은 값으로 고쳤습니다.

### 5. 흐린 잉크 글자 (R-25)
- 글자에 쓰이던 `--ink-faint` 7곳을 `--ink-muted`(다크 #aaa4be, 라이트 #5c566d)로 바꿨습니다: 체결 레인 이름, 마지막 체결 시각, 빈 호가 "-", 입력 안내(`.nx-field-note`), 대출 게이지 보조 글, 미획득 칭호 이름과 조건.
- 비활성 버튼과 입력칸 안내문(placeholder), 선·막대 같은 글자 아닌 곳은 그대로 둡니다.

### 6. 시장 지도 (R-03)
- 칸이 내용보다 좁아지면 이웃 칸을 덮던 원인을 고쳤습니다: 칸 최소 폭 108px, 칸 안 내용은 칸을 넘지 않게(`min-width: 0`, `overflow: hidden`), 등락률은 줄바꿈 금지. 휴대폰에서는 등락률을 16px로 줄였습니다.
- 확인: 375px에서 겹침 0, 가장 오른쪽 칸 끝 345px(화면 375px), 등락률 잘림 0. 1440px에서 15칸 모두 칸 밖으로 넘침 0, 등락률 두 줄 0.

### 7. 공지 버튼 포커스 (감사 오판)
- 공지 창 CSS의 `outline: none`은 레이어 안의 규칙이라, 레이어 밖에 있는 새 화면 공통 포커스 규칙(2px 핑크 외곽선, 2px 띄움)에 집니다. 로컬에서 Tab으로 포커스를 주면 핑크 외곽선이 보이는 것을 확인했습니다. 코드를 바꾸지 않았습니다.

### 8. 없는 주소 (R-27)
- 라우터에 `notFound` 경로를 추가했습니다. 알 수 없는 주소에서는 "없는 화면이에요"와 [홈으로], [시장 보기]를 보여 주고, 창 제목은 "없는 화면 · 슈엔증권"입니다.
- 확인: `/nope-404` → 안내 표시 → [홈으로] → `/`.
- 앱(WebView)이 여는 주소(`/mypage`, `/charge`, `/loan`, `/titles`, `/settings`, `/login`)는 모두 기존 경로라 영향이 없습니다.
