## 확인

- 중복 문구·유색 테두리/외곽선·가로 넘침·한 줄 부품 높이 검사를 375, 1100, 1280px에서 홈, 주식, 종목, ETF, 히트맵, 선물, 옵션, 뉴스, 랭킹, API, 로그인에 실행. 375·1100px은 다크·라이트 모두. 남은 중복은 API 문서의 주문 예제 종류 선택(주식/ETF/선물/옵션)과 같은 글자의 상단 메뉴 하나이며, 역할이 달라 유지.
- 상단 바 순서와 위치는 그대로(메뉴 · 지수 · 밝기 · 로그인).
- `tsc --noEmit` 통과.
- 로그인 상태 화면(내 계좌, 칭호, 설정, 관리자)은 백엔드 없이 띄워 실제 로그인 화면을 보지 못했다.
