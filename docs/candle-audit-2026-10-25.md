# 전 종목 캔들 꼬리 검증 — 2026-10-25

수정 전 `be7fb69`와 수정 후 공통 백엔드 엔진을 비교했다. 15개 종목 모두 3개 시드 평균 꼬리 길이가 감소했다. 평균 길이는 71.21bp에서 61.98bp로 13.0%, 넓은 긴 꼬리 봉은 523개에서 368개로 29.6% 감소했다. 원신은 23.3bp에서 21.3bp, 해당 봉은 24개에서 18개로 줄었다. 긴 꼬리를 없애거나 특정 캔들 모양을 강제한 것은 아니다.

## 공통 엔진 수정

- 목표 보유량 충족 시 불필요한 역방향 배분 주문을 멈추고, 실제 부족·초과 수량만큼 1주 단위로 주문하는 규칙을 소형주에도 적용했다.
- 보유 시간 5초 미만일 때만 적용되던 배분 가격 예산을 모든 보유 시간에 적용했다. 대형주 시간 압축 완화로 이 조건을 빠져나가던 경로를 제거했다.
- 실제 호가 간격과 보정 변동성을 반영한 제한 지정가를 사용한다. 최근 체결·제한된 추정 가치를 혼합하되, 먼 장기 평가가가 배분 축소 매도나 보충 매수를 막지 않는다. 보호 매도와 재고 정리 예외는 유지한다.
- 수동 호가의 위치 분산이 상대 호가를 넘어 공격 주문이 되는 것을 막고, 이미 체결을 선택한 주문은 최초 가격 한도를 유지한다.

가격·시간 우선순위, 실제 체결 OHLC, 이용자 주문, UI, 합의가 확산 계수는 변경하지 않았다. 화면에서 꼬리를 숨기거나 종가를 보간하지 않는다.

## 조건과 지표

15개 종목·6,020명 봇을 동시에 실행했다. 시드 `20261024,7,91`, 각각 60분, 시작가 10,000원, 100ms 배치, 본 게임과 같은 2초 관측 주기다. 첫 1분을 제외한 2,655개 완성 분봉을 비교했다. 격리된 자금·보유 수량으로 실제 주문 매칭을 실행하며 모든 체결의 고가·저가를 보존한다. 운영 DB·이용자 주문·운영 뉴스·스케줄러 지연을 복제한 실험은 아니다. 장르는 실험에서 모두 RPG로 두었다.

## 회귀와 범위

최종 `mvn -q verify` 성공. 별도 전 종목 45개 재현도 성공했고, `SimulationEngineTest` 47개가 통과했다. DB·장시간 부하 등 실행 조건이 필요한 테스트는 조건 없이 실행하지 않았다.

전 종목의 목표량 충족·소량 주문·긴 보유 시간 가격 한도·먼 평가가에서의 배분 실행·수동 호가 분산을 검사한다. 전체 재현에서 현금과 발행 주식 수 대사, 음수 잔액 방지를 확인한다. 유동성 회복 60개 조합은 실제 이용자 매수·매도와 수량·현금 보존을 검사한다. 뉴스 방향·자정 이후 거래·가격제한·상한 근처 유동성도 검사한다.

기존 회귀에서 불필요한 거래를 요구하던 조건도 실제 시장 동작 기준으로 바꿨다. 최소 5주 가정은 배분·회복의 1주 주문을 허용한다. 호재에서 시작가보다 5틱 낮은 체결을 강제하는 대신 실제 체결 고점 대비 2틱 이상 하락과 30초 미만 무체결을 확인한다. 악재는 실제 시작가 아래 체결과 동일 시드 중립 시장보다 낮은 세션 평균 종가를 요구한다. 특정 LP가 반드시 체결 상대여야 한다는 조건 대신 가격 우선순위에 따른 일반 참가자 유동성도 인정하고 실제 이용자 왕복 거래를 검증한다.

검증은 로컬 백엔드 대상이다. 운영 DB 통합·실서비스 부하·모든 장치의 120Hz 보장·운영 배포는 수행하지 않았다. 변경은 주문당 상수 시간 연산이며 프런트엔드 렌더링 경로를 추가하지 않는다. 기존 화면 변경 작업은 이 수정 범위에 포함하지 않았다.
