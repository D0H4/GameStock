# 모바일 앱 네이티브 전환: 다음 할 일

기준: 2026-10-21. 앱(`mobile/`)을 웹 화면을 그대로 띄우는 구조에서 화면별 네이티브 화면으로 옮기는 중이다.

## 지금까지 된 것

| 화면 | 상태 |
|---|---|
| 하단 탭(홈·시장·뉴스·랭킹·설정) | 네이티브 |
| 로그인(이메일·Google·회원가입·비밀번호 찾기) | 네이티브. 앱이 로그인하고 남은 웹 화면에 같은 계정을 넘긴다 |
| 홈 | 네이티브 |
| 시장 목록, 종목 상세, 주문 시트 | 네이티브 |
| 뉴스 목록, 뉴스 상세 | 네이티브 |
| 랭킹(전체·주간) | 네이티브 |
| 설정 메뉴 목록 | 네이티브. 항목을 누르면 아래 화면이 아직 WebView로 열린다 |

## 다음에 만들 화면

남은 화면은 모두 로그인 전용이다. 각 화면은 본래 하는 일만 남기고, 봇 관련 표시는 넣지 않는다.

1. **내 계좌** (`/mypage`)
   - 할 일: 내 돈이 어떻게 됐는지 확인
   - 순자산·손익, 보유 종목(평가액·손익), 미체결 주문과 취소, 체결 내역
2. **충전하기** (`/charge`)
   - 할 일: 오늘의 미션을 하고 보상 받기
   - 미션 3개와 진행 상태, 보상 받기, 프로모션 코드 입력
3. **대출** (`/loan`)
   - 할 일: 빌리고 갚기
   - 한도·담보비율·일일 이자, 대출·상환, 원장, 담보 경고
4. **칭호** (`/titles`)
   - 할 일: 칭호 확인과 장착
   - 조건과 획득 현황, 장착·해제. 칭호 색은 `mobile/src/titles.js`에 이미 옮겨 두었다
5. **프로필·계정 설정** (`/settings`)
   - 할 일: 내 정보 바꾸기
   - 닉네임 변경(변경 가능 시점 안내), 프로필 사진 고르기, 계좌 리셋(확인 단계 포함)
6. **관리자** (`/admin`, 관리자 계정만)
   - 할 일: 운영 조치
   - 사용자 검색·거래 제한과 해제·닉네임 강제 변경, 주문 조회, 공지 작성, 감사 기록
   - 위험한 조작은 웹처럼 사유 입력이나 한 번 더 확인을 거친다
   - 설정 메뉴에는 관리자 계정일 때만 보이게 한다

## 네이티브 전환을 마친 뒤

7. **WebView 걷어 내기**
   - `mobile/src/WebPane.js`, 커스텀 토큰으로 웹에 로그인을 넘기는 코드(`auth.js`의 `syncWeb`), 웹 주소와 탭을 맞추는 코드(`App.js`의 `onRoute`, `PARK_PATH`)를 지운다
   - `react-native-webview` 의존성을 뺀다
8. **정리**
   - 쓰지 않는 예전 아이콘 `mobile/assets/game-icons/{BA,GOV,UMA,ZZZ}.png`
   - `mobile/src/config.js`의 쓰지 않는 Google Client ID 값
   - 쓰지 않는 의존성(`expo-web-browser` 등) 확인
9. **문서 고치기**
   - `docs/mobile-app-setup.md`는 아직 예전 `WebMirrorScreen` 구조를 설명한다. 네이티브 구조와 로그인 흐름으로 고친다
10. **마무리 점검**
    - 새 화면 전체를 antislop으로 점검한다(감사 004)
    - 앱 디자인 체계를 `DESIGN.md`로 기록한다(방향 계약 `.impeccable/surfaces/mobile-src-screens-homescreen-js.md`의 마무리 조건)

## 확인이 필요한 것

- 아이폰에서 종목·뉴스 상세를 밀어서 닫는 동작
- 로그인 창 뒷배경 흐림(특히 Android 기기)
- 실제 주문 접수부터 체결까지(시장가·지정가)

## 앱 밖에서 따로 다룰 것

- **가격 알림 푸시:** Expo Go는 원격 푸시를 지원하지 않는다(SDK 53부터). 개발 빌드(EAS)가 있어야 확인할 수 있다
- **앱 배포:** 서명된 APK·iOS 빌드와 배포 방법(EAS Build)
- **서버 문구:** `price-drivers`의 이유 문장이 관련 뉴스 0건일 때도 "최근 뉴스와 …"로 시작하는 경우가 있다(`MarketService.priceReason`)
