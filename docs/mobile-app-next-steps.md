## 네이티브 전환을 마친 뒤

7. **WebView 걷어 내기**
   - `mobile/src/WebPane.js`, 커스텀 토큰으로 웹에 로그인을 넘기는 코드(`auth.js`의 `syncWeb`), 웹 주소와 탭을 맞추는 코드(`App.js`의 `onRoute`, `PARK_PATH`)를 지운다
   - `react-native-webview` 의존성을 뺀다
8. **정리**
   - 쓰지 않는 예전 아이콘 `mobile/assets/game-icons/{BA,GOV,UMA,ZZZ}.png`
   - `mobile/src/config.js`의 쓰지 않는 Google Client ID 값
   - 쓰지 않는 의존성(`expo-web-browser` 등) 확인
9. **문서 고치기**
   - `docs/mobile-app-setup.md`는 아직 예전 `WebMirrorScreen` 구조를 설명한다. 네이티브 구조와 로그인 흐름으로 고친다
10. **마무리 점검**
    - 새 화면 전체를 antislop으로 점검한다(감사 004)
    - 앱 디자인 체계를 `DESIGN.md`로 기록한다(방향 계약 `.impeccable/surfaces/mobile-src-screens-homescreen-js.md`의 마무리 조건)

## 확인이 필요한 것

- 새 계정 화면 6개를 실제 기기에서 확인(다크·라이트 둘 다). 2026-10-21 기준 Android 번들 빌드만 통과했고 기기 확인은 못 했다
- iPhone Expo Go에서 `Cannot find native module 'ExpoAsset'` 오류: Expo Go와 프로젝트 SDK(57) 버전이 맞는지 확인
- 앱 안 웹 화면의 밝기 연동(`src/next/uiMode.ts`)은 웹을 배포해야 실제 사이트에 반영된다
- 체결 하이웨이(종목 상세), 시장 지도(홈)를 앱에 넣을지 결정

- 아이폰에서 종목·뉴스 상세를 밀어서 닫는 동작
- 로그인 창 뒷배경 흐림(특히 Android 기기)
- 실제 주문 접수부터 체결까지(시장가·지정가)

## 앱 밖에서 따로 다룰 것

- **가격 알림 푸시:** Expo Go는 원격 푸시를 지원하지 않는다(SDK 53부터). 개발 빌드(EAS)가 있어야 확인할 수 있다
- **앱 배포:** 서명된 APK·iOS 빌드와 배포 방법(EAS Build)
- **서버 문구:** `price-drivers`의 이유 문장이 관련 뉴스 0건일 때도 "최근 뉴스와 …"로 시작하는 경우가 있다(`MarketService.priceReason`)
