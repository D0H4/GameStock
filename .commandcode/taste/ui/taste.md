# UI / Design

- When asked to redesign or refactor a screen, prefers to keep the existing design language/style as much as possible and refine it into something cleaner (incremental polish) rather than introducing a wholesale new visual direction. Confidence: 0.6
- Prefers decluttering the UI by removing unnecessary explanatory text/labels. Confidence: 0.55
- Is open to rearranging/relocating layout elements as part of a cleanup, not just cosmetic touch-ups. Confidence: 0.5
- Distinguishes removing redundant explanatory text from removing working functionality: expects existing functional controls (e.g. chart interval/candle-vs-line selectors) to be preserved during a cleanup/redesign, and reacts negatively when a feature has disappeared. Confidence: 0.55
- Maintains a personal design-system skill ("doha-ds") and expects the agent to invoke it when doing UI/design work (e.g. redesigns). Confidence: 0.6
