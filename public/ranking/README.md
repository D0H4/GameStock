# Ranking avatar frames

Generated with the built-in image_gen tool from the user-approved gold frame.
PNG assets retain alpha transparency and are resized to 192px for 56px display.
The original generated images remain outside the app; these files are the shipped assets.

- medal-gold.png: approved original frame
- medal-silver.png: silver variation
- medal-bronze.png: bronze variation

## Final variation prompts

Silver:
Create the SILVER version of this exact avatar frame. Preserve all geometry, framing, transparent center and outer background, narrow double rim, black annulus, delicate laurel placement and size exactly. Change ONLY gold metal to muted neutral silver/platinum. No additions, no numbers, no crown, no new ornaments. Same square canvas and object position. Actual alpha transparency in center and outside.

Bronze:
Create the BRONZE version of this exact avatar frame. Preserve all geometry, framing, transparent center and outer background, narrow double rim, black annulus, delicate laurel placement and size exactly. Change ONLY gold metal to muted antique copper bronze. No additions, no numbers, no crown, no new ornaments. Same square canvas and object position. Actual alpha transparency in center and outside.
